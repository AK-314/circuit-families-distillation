# Scientific red-team resolution matrix

**Status:** prospective design resolution; exact numeric choices remain open

**Red-team timing:** after technical Stage 10 and before definitive production

**Definitive follow-up data inspected:** none

This file records the current disposition of the broad scientific red-team.
It is not a claim that every implementation or numeric setting is already
frozen. Concrete consequences are governed by the post-red-team protocol
amendment and Stages 11--14.

| Issue | Disposition | Protocol consequence | Remaining decision |

## Closed versus open

The broad criticism-gathering phase is closed. New criticism is considered only
if it identifies a concrete flaw not represented above. Exact values and
implementation choices remain open until their assigned Stage 11--14 gates.

The scientific design is therefore neither "unchanged" nor "fully frozen." It
is an amended prospective design with a finite list of work required before
production.
