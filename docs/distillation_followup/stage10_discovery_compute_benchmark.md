# Stage 10 discovery compute benchmark

Stage 10 benchmarks the accepted centred-logit exact evaluator, component
ranking pass, greedy-deletion adapter, and diversity-forced adapter on one
physically verified registered teacher. The run records timings, budget units,
budget consumption, deterministic evidence hashes, memory, and projections.
It does not record or display endpoint values.

Method-native units remain explicitly non-equivalent. The common exact-mask
allowance is separately accounted. Threshold, component-cap, overlap, and
packing sensitivity can be recomputed from masks already present in a sealed
ledger; changing a threshold that controls the discovery trajectory may still
require a new search.

All measured budgets remain technical fixtures. Stage 10 does not select the
production method roster, native budgets, exact allowance, concurrency, or
sensitivity grid, and it begins neither Stage 11 nor scientific red-teaming.
