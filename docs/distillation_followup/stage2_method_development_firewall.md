# Stage 2 Method-Development Firewall

## Status

This is the authoritative Stage 2 method-development firewall.

It governs technical pilots and accidental pre-freeze endpoint-producing output.
It does not authorize definitive scientific endpoint production.

## Permitted technical-pilot purposes

Technical pilots may be used only for purposes such as:

- software correctness and interface validation;
- loader, mask, adapter, and exact-evaluation plumbing;
- runtime, memory, numerical-stability, and feasibility checks;
- determining whether a method can execute;
- technical evidence needed to assign later prospective native budgets;
- deterministic serialization, provenance, isolation, and merge checks;
- synthetic or fixture execution that cannot reveal definitive scientific effects.

Calling an activity a pilot does not exempt it from this firewall.

## Prohibited scientific selection

Pilot output must not be used to choose or revise protocol values according to
apparent phase, condition, student, circuit, or endpoint effects.

In particular, pilot evidence may not select:

- teacher seeds, checkpoint identities, or phase landmarks;
- student architecture, initialization, replication, attempt caps, replacement,
  or minimum eligibility;
- hard- or soft-training settings;
- the final soft target, temperature, tolerance, or eligibility rule;
- fidelity implementation details, threshold, denominator guard, or precision;
- Endpoint 2 component cap, overlap metric, or overlap cutoff;
- discovery roster, method versions, or native budgets based on apparent
  scientific effects;
- the common exact-mask-evaluation allowance based on apparent scientific effects;
- primary contrasts, cell summaries, missing-cell rules, or required analysis outputs;
- definitive production scope.

## Excluded-development boundary

Endpoint-producing development artifacts belong under
`followup/excluded_development/` or in an approved local/external development
location recorded canonically as excluded.

Excluded development output has:

- `primary_analysis_eligible = false`;
- `scientific_selection_eligible = false`;
- no authority to satisfy a definitive production cell;
- no authority to enter primary estimates, tables, figures, or claims.

Small reviewable exclusion metadata is tracked in
`followup/manifests/stage2_excluded_development_register_v1.json`.

## Required tracked exclusion metadata

Every excluded endpoint-producing artifact must receive a stable exclusion entry
recording:

- exclusion ID;
- portable artifact identity;
- development context;
- reason for exclusion;
- whether endpoint values were emitted;
- `primary_analysis_eligible = false`;
- `scientific_selection_eligible = false`;
- `regeneration_required = true`;
- the later stage/freeze after which regeneration is valid;
- disposition;
- `promotion_in_place_permitted = false`.

Private absolute paths are not canonical artifact identities.

## Accidental endpoint-producing output

If a technical pilot accidentally emits endpoint or endpoint-like scientific
output, it is registered rather than silently deleted or promoted.

Registration preserves provenance. It does not legitimize the output.

The artifact may not be copied, renamed, reclassified, or promoted into the
definitive result namespace.

## Mandatory post-freeze regeneration

Any excluded endpoint-producing output needed for definitive analysis must be
regenerated after all relevant prospective freezes and after the corresponding
production stage is authorized.

The definitive result must arise from that authorized post-freeze execution.
A pre-freeze output cannot become definitive merely through reclassification.

## Predecessor and path boundary

The predecessor repository is immutable and is never an authorized development
output root.

Canonical exclusion identities must be portable repository-relative identities.
They must not contain parent traversal, private absolute paths, or resolve into
the predecessor repository.

## Scientific boundary

This firewall is governance only. Apparent pilot phase or condition effects are
forbidden evidence for choosing prospective scientific protocol values.
